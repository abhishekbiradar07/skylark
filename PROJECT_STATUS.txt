DECISION LOG HIGHLIGHTS
================================================================================

1. Technology Choices
   - FastAPI: Async support, auto docs, Python ecosystem
   - Pandas: Data processing, proven library
   - Pydantic: Type safety, validation
   - GraphQL: Monday.com native API

2. Dynamic Normalization
   - In-memory only (never writes back to Monday)
   - Preserves raw values for audit trail
   - Flags quality issues instead of guessing
   - Conservative defaults (e.g., 0.3 probability)

3. Cross-Board Strategy
   - Sector-level aggregation ONLY
   - NO forced deal-level joins (unreliable in data)
   - Clear communication that it's sector-level analysis
   - Based on actual data audit findings

4. Data Quality Approach
   - Transparent reporting of issues
   - Explicit exclusions (e.g., "7 deals excluded")
   - Quality flags on every record
   - Summary statistics exposed to user
